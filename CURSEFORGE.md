# Addon Skins (DaylightUI Plugin)

**Your other addons' windows in the Daylight UI look:** the window shell, your font, text colors and accent, and Daylight UI's buttons, boxes and scroll bars.

A plugin for Daylight UI, by Glowey (not part of Daylight UI itself: report its bugs here, not to Daylight UI). Requires **Daylight UI** with its **Window Skins** module on.

---

## Addons it skins

ALL THE THINGS · Altoholic · Auctionator · BugSack · Camping Kit · Dialogue UI · DoesItDie · Dungeon Journal · Forever Fishing · Forever Leveling BiS · Guildy · High Fidelity World Map · Journey Guides · Keep or Toss · Kerzo Classic Quest Log · Kerzo Quest Expansion · LayerSwap · Leatrix Plus · LFG Forever · LootTriage · Mastercraft · OneForAll · OpenMap · Polestar · Questie · RareScanner · Shortest Path Forever · Spoken · Total RP 3 · TrueshotLodge

Only the ones you have installed are skinned; the rest are skipped. Nothing to set up: each takes the Daylight UI look the next time you open its windows.

**Polestar:** the Daylight UI look goes on Polestar's own "Polestar" skin only. Its other looks (Vellum, Beacon and the rest) are yours to use and stay as Polestar draws them.

## The game's own windows

The game windows Daylight UI's Window Skins leave bare get the same look: the ready and role checks, queue, invite and PvP popups, the color picker, the "Return to graveyard" button and death recap, the stopwatch and Quick Keybind, chat settings and the channels window, the zone map (Shift-M), alert and level-up toasts, help, report and friend windows, icon pickers, help tips and more. Also the **Options window** (Esc > Options), every setting in it and the addon pages inside it, and the **dungeon-ready dialog**. New in 1.12.0: the **profession window**, the **character window** (and currency transfer), Collections tabs, the Calendar panels, Click Casting, the Cooldown Manager settings, guild bank tabs, confirm boxes' gold and item lines, the map pin button, and the game's own gossip, quest, vendor, trainer, mail, social, bag and bank windows whenever Daylight UI's own version is switched off. With Daylight UI 1.8.4, which dresses the gossip, quest, vendor, trainer, mail, social, character and spellbook windows itself when you pick them, those are left to Daylight UI so nothing is dressed twice. New in 1.12.2: new-player tutorials, battleground status bars, voice chat toasts, GM chat, the subscription offer, the game's damage meter and more. Edit Mode stays the game's.

All pop-up menus (right-click menus and dropdowns, any addon's) and every addon's AceConfig settings lose the game's gold.

## Daylight UI Override

Some addons do things Daylight UI already does (OneForAll's chat and minimap tools, Questie's nameplate icons, Total RP 3's tooltip, and so on). The first time you log in with one of them, a window lists each overlap with Daylight UI picked. Switch any back to the addon if you'd rather keep its version.

Nothing is lost: the addon's own setting is switched off and kept, and can be given back at any time.

---

## Settings

Daylight UI options > **Plugins > Addons**:
- **All windows:** switch the skin off for any one addon or any one game window;
- **Look and Feel:** give an addon a look of its own (font, outline, shadow, size, window opacity, border, bevel, and for some its text colors and accent) with **Custom Settings**, or change Daylight UI's own look on its General tab;
- change the Override choices on the addon's **Extras** tab, or **Give everything back**;
- open the Override window again with **Show the choices again** on the All windows page.

It never changes other addons' files. It only changes their settings for features you hand over to Daylight UI, and puts them back as they were when you give them back.
