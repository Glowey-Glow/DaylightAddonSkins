# DaylightUI Addon Skins

A plugin for DaylightUI on WoW: Forever. It dresses your other addons' windows in the DaylightUI look: the window shell, your font, text colours and accent, and DaylightUI's buttons, boxes and scroll bars.

**Addons it skins:** Keep or Toss, DoesItDie, Camping Kit, LootTriage, OpenMap, Spoken, Forever Fishing, Polestar, Forever Leveling BiS, Journey Guides.

**Settings:** DaylightUI options, Plugins, Addons. Each addon can be switched off, and each has its own page (font, outline, shadow, size, window opacity, border, bevel). Turn on "Use my own settings" on a page to give that addon a look of its own.

Needs DaylightUI with its Window Skins module on. It never changes the other addons' files.
