# Addon Skins (DaylightUI Plugin)

A plugin for Daylight UI on WoW: Forever. It gives your other addons' windows the Daylight UI look: the window shell, your font, text colors and accent, and Daylight UI's buttons, boxes and scroll bars.

**Addons it skins:** BugSack, Camping Kit, Dialogue UI, DoesItDie, Dungeon Journal, Forever Fishing, Forever Leveling BiS, Journey Guides, Keep or Toss, LayerSwap, LootTriage, OneForAll, OpenMap, Polestar, Questie, RareScanner, Shortest Path Forever, Spoken, Total RP 3, TrueshotLodge.

## Requirements

- Daylight UI, with its **Window Skins** module turned on.
- Any of the addons above. Only the ones you have installed are skinned; the rest are skipped.

## Installing

Install it from CurseForge (or WowUp), or unzip it into `World of Warcraft\_forever_\Interface\AddOns`. Make sure it's ticked in the AddOns list on the character screen, then log in or `/reload`.

## How to use it

There's nothing to set up: once it's installed, every supported addon you have takes the Daylight UI look the next time you open its windows.

**Daylight UI Override.** Some addons do things Daylight UI already does (OneForAll's chat and minimap tools, Questie's nameplate icons, Total RP 3's tooltip, and so on). The first time you log in with one of them, a window lists each overlap with Daylight UI picked. Switch any of them back to the addon if you'd rather keep its version. Nothing is lost: the addon's own setting is switched off and kept, and can be given back at any time.

**LayerSwap's minimap button.** With LayerSwap installed, a "Layer: B" button sits in the bottom-left corner of Daylight UI's minimap. Left-click opens LayerSwap's panel, right-click its layer menu, shift + right-click its settings. Choose whether it shows all the time, only with the mouse over the map, or not at all on LayerSwap's page (Minimap tab).

## Settings

Open the Daylight UI options and go to **Plugins → Addons**. There you can:

- switch the skin off for any one addon;
- give an addon a look of its own (font, outline, shadow, size, window opacity, border, bevel, and for some its text colors and accent) with **Use my own settings** on its page;
- change the Override choices on the addon's **Daylight UI** tab, or use **Give everything back** there;
- open the Override window again with **Show the choices again** on the All windows page.

It never changes the other addons' files. It only changes their settings for features you hand over to Daylight UI, and puts them back as they were when you give them back.
